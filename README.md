# Machine learning in the reverse computation of 2 layer planar model based on FD-NIRS measurements at 110 MHz.
This repository includes the codes used for Monte Carlo simulation in 2 layer planar model and the revserse computation. There are three folders in this repository: fitting, papers, and simulation. the fitting folder includes codes used for reverse computation using different machine learning and mathematical models, the paper folder includes the related papers with our research, the simulation folder contain the code used for Monte Carlo simulations. <br>

The whole process includes both the forward and backward computation. Forward computation will start from Sobel sampling of the optical properties of the 2 layer planar model, and end with the FD-NIRS measurements. The main tool used for the forward computations are Monte Carlo (MCX package) simulation and Fourier transform. Time resolved spetroscop were obtained from simulations and FD-NIRS measurements were obtained from fourier transform from TD-NIRS measurements. In total, 11000 simulations were conducted to get 11000 FD-NIRS measurements. <br>
The inverse process were mainly conducted by machine learning approaches. These approaches include four variants of KNN, XGBoost, Gradient Boost, Catboost. IN this process, the FD-NIRS measurements were fed into models and the optic properties were predicted. The mean squre error and mean percentage error were measured for different ML models. The main purpose of the study is to comprehensively test the performance of different ML models in the 2-layer planar model reverse computation. <br>
